to download it:

1. click the green **Code** button near the top of the page
2. click **Download ZIP**
3. open your Downloads folder
4. right-click the ZIP file and choose **Extract All**
5. open Visual Studio Code
6. click **File → Open Folder**
7. choose the extracted website folder

make sure you open the whole folder and not just one file, because the site needs the `js` and `images` folders to work properly

`index.html` is the homepage
